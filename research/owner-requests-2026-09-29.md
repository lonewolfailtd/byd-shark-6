# What Shark owners are asking for, 29 Sep 2026

Source: recent Sharkware threads in the BYD Shark Owners Club Australia Facebook group, read by hand
through Tane's own login. Names left out on purpose. Re read the group on request, never on a timer.

## Feature requests

| Request | How often | Our position |
|---|---|---|
| Sentry while parked | Very often | Powered sentry built. Locked sentry ruled out by the no power rule |
| Hill descent button on the off road page | Several | BYD setter exists. Driving aid, so needs Tane's say so |
| Off road toggles on the right for easy reach | Several | Layout change, easy |
| Bigger text for tyre pressures and gauges | Several | Add a large text option |
| Plain dark skin for night, big simple buttons | Several | Add a plain skin with no photograph |
| One press to put the map back on the driver display | Several | In settings memory as "Map on the driver display" |
| Remember the annoying warnings after each start | Very often | Settings memory built |
| Open the app when the ute starts | Popular | To check against the no keep alive rule. A start on boot is not a keep alive |
| App shortcuts on every page, not only Home | Some | Easy |
| Range worked out from the last 50 km | Some | Fuel page uses fill to fill. Add rolling figure |
| Fuel range that does not fall from 50 km to zero | Some | Same work as above |
| Save dashcam clips to USB and to a phone | Some | USB already first choice. Phone transfer not built |
| One push unlocks driver door only | One | Body control, not explored |
| Sand and mountain modes while towing | One | BYD limitation, not ours to change |

## Buying and install feedback

- People dislike the dashcam subscription. One time price, or a three or five year licence, is wanted.
- Install works best with the laptop and ute both on a phone hotspot. Home wifi often fails.
- The licence code is too long to type. Use a short code or a QR code.
- People ask to install from a phone with no laptop.
- Pointer trails after install come from Android developer options. Our installer should switch them off.
- Support emails going unanswered for a week caused public complaints.
- People want a video demo before buying.

## Worries we must answer on the sales page

- Warranty. Owners ask whether a side loaded app voids it. Needs plain wording and no promises.
- Servicing. Dealer updates may wipe the app or switch debugging off.
- Safety. One owner called side loaded software a high risk change with no independent security check.
  Our answer is the written rule set: reads unlimited, writes limited to what BYD's own screen does,
  every write read back, never brakes, stability or firmware.
